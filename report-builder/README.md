# 주간자금일보 사이트 생성 도구

매주 다른 `.xlsx` 파일을 읽어 원본 보고서 형식의 표, 계좌별 주요 입출금 설명, 현금·외화·주식·자산 총계 추이 그래프를 포함하는 독립 `index.html`을 생성합니다.

## 사용

1. `report-builder/`에서 엑셀 파일을 선택합니다.
2. 주간자금일보·일일내역·그래프 시트를 확인하고 보고서 사이트를 생성합니다.
3. 미리보기에서 거래 설명과 그래프를 확인합니다.
4. `보고서 사이트 저장`으로 `index.html`을 저장하거나 `게시용 내용 복사`를 클릭합니다.
5. GitHub의 `reports/latest/index.html`을 생성한 내용으로 교체하고 커밋합니다.
6. Pages 배포가 완료되면 방문자는 `reports/latest/`의 같은 주소에서 최신 보고서를 봅니다.

## 처리 규칙

- 주간 보고기간과 기존 모비스 양식을 내용으로 인식합니다. 탭 이름은 매주 달라질 수 있습니다.
- 일일내역은 보고기간에 해당하는 거래만 읽습니다.
- 은행·통화·입출금 방향과 합계를 대조합니다. 은행에 출금 또는 입금이 있는 계좌가 하나이고 합계가 일치할 때만 계좌 거래로 연결합니다. 여러 계좌로 분리할 근거가 없으면 은행별 참고내역이라고 표시합니다.
- 주요 거래는 금액 순 상위 3개를 보여주며, 가장 큰 거래와 매출대금 입금처에 따라 문장을 생성합니다.
- 그래프의 중복 날짜와 구성금액·총계 불일치 시점은 제외하고 참고사항에 표시합니다. 최신 점은 주간 보고서의 금액을 사용합니다.
- 생성된 사이트는 외부 라이브러리나 네트워크 요청 없이 단독으로 동작합니다. hover, 클릭 고정, 키보드 포커스와 Esc 닫기를 지원합니다.
- 원본 엑셀은 서버나 저장소에 올라가지 않습니다. 계좌번호는 끝 4자리만 포함하고 일일자금일보의 거래처와 내용은 원문 그대로 포함합니다.
- GitHub Pages에 게시한 결과는 공개 페이지입니다. 자동 게시를 위한 토큰이나 비밀번호는 수집하지 않습니다.

기존 전주 이월 도구는 저장소 루트에서 계속 사용합니다.

## 보고서 출력

미리보기 및 생성한 사이트의 `보고서 양식 보기`에서 A4 가로의 주간 요약 3쪽과 마지막 일일자금일보를 확인하고, `PDF / 인쇄`에서 PDF로 저장합니다. 출력은 결재란과 총액 비교·자산 추이, 현금·예금 상세와 소계, 주식 현황·증감 그래프, 일일자금일보 순서입니다. 일일내역은 보고기간의 날짜/구간별 거래처·내용·은행별 금액·외화·소계·입출금 차액·전일/당일잔액을 보존합니다. 거래가 없는 입금/출금 구간은 `자금내역없음` 한 줄로 표시하고, 내용이 많으면 표가 늘어나며 인쇄 시 다음 쪽으로 이어집니다. 원본에서 여러 날짜를 묶어 작성한 구간은 그대로 표시합니다. 금액이 아직 없는 일정도 내용이 있으면 포함합니다. 웹 입출금 요약에는 거래 계좌만 표시하고 출력 잔액 및 총계는 전체 계좌를 포함합니다. 원자료에 종목별 과거 주가가 없으면 전주 환산주가(전주 평가금액/금주 보유수)와 금주 주가를 비교합니다.
