매주 게시하는 방법
  1. 게시용 내용 복사를 클릭합니다.
  2. GitHub에서 교체를 열고 파일 내용을 전체 선택한 뒤 붙여넣습니다.
  3. Commit changes로 저장하면 게시된 보고서가 갱신됩니다.

방문자는 게시된 보고서의 같은 주소에서 최신 내용을 봅니다. 생성한 index.html을 저장해 GitHub에 직접 올려도 됩니다.

GitHub Pages의 보고서는 주소를 아는 사람이 열람할 수 있습니다. 원본 엑셀은 포함되지 않으며, 계좌번호는 끝 4자리만 표시합니다. 일일내역의 거래처와 내용도 게시됩니다.
