# 회사 업무용 주간자금일보

개인 프로그램과 분리된 회사 업무 전용 저장소입니다.

- `.xlsx` 파일을 드롭하고 생성 기준일, 모비스·휴네시온·현대차 주당가격, EUR·GBP 환율을 입력합니다.
- 이전 보고서의 금주 금액을 새 시트의 전주로 이월합니다.
- 원본 시트를 보존하고 새 기간 시트만 추가합니다. 새 기간 입출금은 사용자가 엑셀에서 작성합니다.
- 파일 처리는 브라우저에서 수행되며 원본 엑셀은 서버로 전송하지 않습니다.

GitHub Pages: https://holaharu.github.io/work-cash-report/

`vendor/`의 JSZip 라이선스는 동봉된 파일을 참고합니다.
